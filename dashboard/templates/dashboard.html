Run an agent

Browse to your model for the agent you want, then press Run. Agents run one at a time.

⚙️ How it works — 3 ways to read the model

1. PBIP / TMDL (fully offline). Choose a .pbip/.zip or type a folder path. The model is parsed straight from TMDL text — no Power BI Desktop, no engine. A binary .pbix can't be read this way (its model is a VertiPaq image), so File → Save as → Power BI Project (.pbip) once to unlock it.
2. Already open. If the model is open in Power BI Desktop, the dashboard reads it live from the local engine (ADOMD) — this is tried automatically.
3. Launch for me. Choose a .pbix with nothing open and the result offers “Launch Power BI Desktop & run” — it opens the file, reads it, and closes it.
🔒 Private & local. Every agent runs entirely on your own machine. Your .pbix/.pbip is read and processed locally by this app — nothing is uploaded to, transmitted to, or stored on any external server or cloud service.
