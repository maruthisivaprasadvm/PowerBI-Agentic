⚡ Power BI Performance Analyzer — Workflow

How any Power BI developer turns a Performance Analyzer export into a ranked, rule-checked performance dashboard. Runs fully offline on the exported .json — no live connection needed.

Lane 1 · Capture in Power BI Desktop

1

Open Performance Analyzer

Power BI Desktop → View → Optimize ribbon → Performance Analyzer.

→
2

Record

Start recording, then Refresh visuals or interact with the page you want to measure.

→
3

Export JSON

Click Export → saves a .json (schema performanceAnalyzerExport). Drop it in the project.

Lane 2 · Analyze (the agent)

4

Run the agent

@perf-analyzer-agent analyze the export "myreport.json" — input is just the file name.

→
5

Parse event tree

Aggregates each visual into DAX query, Visual display, Other; counts DirectQuery & rows; grabs DAX text.

→
6

Evaluate rules

Checks rules/performance/PerfRules.json thresholds (slow DAX, slow render, overhead, DirectQuery, too many visuals…).

Lane 3 · Review & optimize

7

Timestamped report

Writes output\PerformanceAnalyzer\<export>\<export>_<timestamp>.html. Each export keeps its own history.

→
8

Dashboard opens

KPI cards, top visuals by total time (stacked), rules pass/fail with offenders, and a per-visual table with DAX text.

→
9

Fix biggest wins

Start with the slowest DAX. Re-export after changes and compare timestamped runs to confirm it got faster.

Input / Output contract

INPUT
A Performance Analyzer export (.json) from Power BI Desktop.
OUTPUT
A self-contained HTML dashboard per run — ranked slow visuals + failed performance rules + remediation.
output/ PerformanceAnalyzer/ SalesReport/ SalesReport_20261022-174059.html SalesReport_20261101-090210.html <- history BPA/ <- the BPA tool's reports (separate) AI Summaries/ ...

Per-visual categories

DAX query — model/measure time Visual display — rendering time Other — queue / prepare / blocked

Rule categories

VisualDAXRendering OverheadDirectQueryReport

Thresholds live in rules/performance/PerfRules.json — tune them to your performance budget. Severity 1→5.
