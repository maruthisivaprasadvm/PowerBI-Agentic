Runs one at a time, entirely in your browser. The report opens as a self-contained HTML file you can download and share.
🔒 Private & local. Your Power BI files are read and parsed inside this web page (Python compiled to WebAssembly). They are never sent to, stored on, or transmitted to any server or cloud service. Close the tab and nothing remains.
Powered by the same open parsers as the local Power BI Agentic app · runs via Pyodide (Python → WebAssembly)
